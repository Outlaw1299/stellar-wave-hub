# Research: Soroswap - Stellar Wave Project Submission

Soroswap is a decentralized exchange built on Stellar's Soroban smart contract platform. It solves liquidity fragmentation by pooling assets. It uses constant product formula, factory and pair contracts, and price oracles. The project applies Stellar's low fees and fast settlement. It was part of Stellar Wave and has a verified contract ID. This is a short original description for the Hub.
